# Referências

O `.bib` desta pasta é a fonte única de verdade das referências do capítulo — toda
citação no texto deve remeter a uma entrada dele, e ele é o que se versiona.

PDFs dos artigos/materiais citados podem ficar aqui para consulta local, mas **não
são versionados** (ver `.gitignore` na raiz do repositório): são material de
terceiros, obtidos sob direitos autorais próprios, e recuperáveis nas fontes
originais a partir das entradas do `.bib`.
